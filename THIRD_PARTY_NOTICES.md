## Модели LLM

### DeepSeek-V4.1-Flash
- **Провайдер**: DeepSeek
- **Использование**: основная модель для чат-ответов Альфа-агента и Новостного агента при доступном API; без ключа или при ошибке API работает явный локальный демо-режим
- **Доступ**: через OpenAI-совместимый API хакатона, ключ только в `.env`
- **Лицензия**: используется в рамках хакатона «Альфа Хак» 2026

### GLM-5.3-Flash, Qwen3.6, Gemma 4, Kimi K2.6
- **Провайдеры**: Zhipu AI, Alibaba, Google, Moonshot AI
- **Использование**: допустимые альтернативные модели для экспериментов и сравнения качества
- **Доступ**: через тот же API хакатона; в коде по умолчанию не активированы

### Внешний OpenAI-совместимый API
- **Использование**: единственный канал вызова LLM; настраивается через `LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY`
- **Ограничение**: разрешены только модели из списка хакатона; при недоступности API сервис явно переходит в локальный демо-режим и не обращается к сторонним/локальным провайдерам
- **Секреты**: ключ хранится только в `.env`, не попадает в git, Docker-образ и ответы API

## Смоделированные интеграции

- **Внутренняя база клиентов**: CSV + поиск похожих компаний, без реального
  master data и ИНН.
- **Аутентификация**: демо-аккаунты с PBKDF2-хешем и `localStorage` на клиенте;
  без SSO и серверных сессий.
- **Хранилище**: `.run/` вместо промышленной БД; журнал аудита и отзывы — JSONL.
- **Реклама банковских продуктов**: в интерфейсе не реализована; при
  необходимости добавляется как отдельный помеченный блок.
